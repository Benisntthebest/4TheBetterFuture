# 4TheBetterFuture

## Thư viện Trò chơi
1. **Phân loại Rác (10 Màn chơi)**: Băng chuyền 2D 60fps với cơ chế khóa cứng thùng, logic HOẶC / KHÔNG PHẢI, thuộc tính vật lý, Trạm Rửa Sạch (Loop), tối ưu 3 Sao ⚡ và Gợi ý / Đáp án sau 2 lần thử chưa đạt.
2. **Robot Mê Cung (ThinkPlay v5)**: Game coding kéo thả dạng Scratch nằm trong `games/robot-maze/`.

## Đồng bộ Database giữa nhiều máy
- Mặc định trình duyệt dùng `localStorage` riêng trên từng máy.
- Để mọi máy dùng chung Database: vào **Admin & DB** (`Admin` / `xhauwfihf09124`) và dán link **Firebase Realtime Database** vào mục **Cloud Sync**, hoặc xuất `data/database.json` rồi commit lên GitHub.
